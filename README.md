# CSV Writer Library

Универсальная Java библиотека для генерации CSV файлов с использованием Reflection и аннотаций.

##  Возможности

- **Автоматическая генерация CSV** на основе Reflection и аннотаций
- **Поддержка коллекций** - автоматическое разворачивание в отдельные колонки
- **Умное форматирование** различных типов данных (String, Number, Boolean, LocalDate, LocalDateTime)
- **Экранирование CSV** - корректная обработка специальных символов
- **Гибкая настройка** заголовков колонок через аннотации
- **Обработка ошибок** с информативными сообщениями

##  Установка и запуск

### Сборка проекта

```bash
mvn clean compile
```

### Запуск примеров

```bash
mvn exec:java -Dexec.mainClass="org.writer.Main"
```

### Запуск тестов

```bash
mvn test
```

##  Особенности реализации

### Экранирование CSV

- Все значения оборачиваются в двойные кавычки
- Внутренние кавычки удваиваются
- Null значения преобразуются в пустые строки

### Фильтрация полей

В CSV включаются только поля, помеченные аннотацией `@CsvColumn`.
